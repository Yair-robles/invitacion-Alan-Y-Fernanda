## Publicar en GitHub Pages

1. Descomprime este ZIP.
2. Crea un repositorio en GitHub (por ejemplo, invitacion-alan-fernanda).
3. Sube los archivos descomprimidos a la raíz del repositorio. index.html y osito.png deben quedar juntos, sin una carpeta adicional.
4. En Settings → Pages, selecciona Deploy from a branch, la rama main y la carpeta / (root). Guarda.
5. Cuando termine la publicación, GitHub Pages mostrará el enlace de tu invitación.

No subas solamente el ZIP: GitHub Pages necesita los archivos descomprimidos.

## Archivos

- index.html: invitación completa, estilos y confirmación por WhatsApp.
- osito.png: ilustración.
- .nojekyll: permite servir directamente los archivos estáticos.

No requiere instalación, servidor PHP, base de datos ni compilación. Puedes abrir index.html para revisarla localmente. Las fuentes de Google requieren internet; si no cargan, se utilizan fuentes de respaldo.
